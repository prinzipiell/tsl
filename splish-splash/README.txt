UPLOAD
Upload the contents of this dist folder to your web server, preserving its subfolders. Open index.html through the website URL. It also works in a subdirectory.

HTTPS is required for WebGPU on a remote server. Use a browser/device with WebGPU support. Localhost is allowed for local testing. Opening index.html as a file is not supported.

No npm install, build step, Node server, CDN, or runtime download is needed. Serve .js as text/javascript, .css as text/css, .png as image/png and .ttf as font/ttf. No special routes are required.

Included: Three.js 0.186.0, WebGPURenderer/TSL fluid simulation, Tweakpane 4.0.5, Cinzel font, and the selected equirectangular panorama. Initial view: 75 degrees. Particles: 32,768. Flow: 5.85. Radius: 0.57. Absorption: 0.75. Hover splashes; left-drag rotates; scroll zooms. R re-forms the knot.

The page is titled Splish Splash., Tinker Day #46. The previous-day link points to https://dasprinzip.com/tinker/day45/.
